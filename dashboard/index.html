How to read this map

  1. Each card is a screen of the app. The same screen in another language, text size or device is one card.
  2. Each colored line is a tester, an AI persona with its own phone, language and goal. Follow it from Launch to see where the tester went. Click a name at the top left to show only its path.
  3. Gray dashed lines are screens only the robot opened: it taps every button once, with no model, so the map shows every screen, also those no tester found.
  4. The heat map on a screen shows where fingers landed, or where they are likely to land.
  5. Click a card to see its screenshots, the findings seen there, and to turn a finding into a check that each replay of the path verifies.

Each path is a trace that replays with no model: Explore, then Compile, then Replay.
